# Adaptive Graph-Based Timetable Optimization & Recovery Framework
### DAA Final Project | C++14 + Vanilla HTML/CSS/JS

---

## 📁 Project Structure

```
DAA_Project/
│
├── src/                        ← C++ source modules
│   ├── data_model.h            │  Shared structs + global externs
│   ├── data_init.h/.cpp        │  Sample data initialization
│   ├── conflict_graph.h/.cpp   │  Build conflict graph [O(n²)]
│   ├── greedy_coloring.h/.cpp  │  Welsh-Powell greedy coloring [O(n·S·R)]
│   ├── backtracking.h/.cpp     │  Backtracking solver [O(n!·S·R)]
│   ├── timetable_gen.h/.cpp    │  Generation orchestrator
│   ├── fragility.h/.cpp        │  Pre-disruption risk analysis [O(n·S·R)]
│   ├── bfs_dfs.h/.cpp          │  BFS + DFS disruption traversal [O(V+E)]
│   ├── max_flow.h/.cpp         │  Edmonds-Karp max flow [O(V·E²)]
│   ├── recovery.h/.cpp         │  Recovery engine (Bipartite + Flow)
│   ├── json_writer.h/.cpp      │  JSON output serializer
│   ├── complexity.h/.cpp       │  Complexity analysis printer
│   └── main.cpp                │  Entry point
│
├── frontend/                   ← Web frontend (no build step)
│   ├── index.html              │  Main HTML
│   ├── css/
│   │   └── style.css           │  Dark-theme stylesheet
│   └── js/
│       ├── app.js              │  State management + tab control
│       ├── timetable.js        │  Timetable grid renderer
│       ├── fragility.js        │  Fragility table + risk bars
│       ├── graph.js            │  Conflict graph canvas
│       ├── flow.js             │  Max-flow network SVG
│       ├── algorithms.js       │  Algorithm info cards
│       └── recovery.js         │  Recovery panel
│
├── output/
│   └── timetable.json          ← Generated by C++ (read by browser)
│
├── build/
│   └── timetable.exe           ← Compiled binary
│
├── Makefile                    ← Linux/Mac build
├── run.bat                     ← Windows one-click runner
└── README.md
```

## 🚀 Quick Start

### Windows (one-click)
```
Double-click run.bat
```

### Manual (Windows)
```batch
g++ -std=c++14 -O2 -Isrc -o build\timetable.exe src\*.cpp
build\timetable.exe room 0
start frontend\index.html
```

### Linux / Mac
```bash
make
make run
xdg-open frontend/index.html   # or: open frontend/index.html
```

## 🏗️ Algorithmic Pipeline

```
INPUT: 15 classes, 4 teachers, 5 rooms, 20 slots
        ↓
[conflict_graph]  Build adjacency list   O(n²)
        ↓
[greedy_coloring] Welsh-Powell coloring  O(n·S·R)
        ↓  (if greedy fails)
[backtracking]    Exhaustive search      O(n!·S·R)
        ↓
[fragility]       Risk scoring           O(n·S·R)
        ↓
    DISRUPTION EVENT
        ↓
[bfs_dfs]         Affected region        O(V+E)
        ↓
[max_flow]        Edmonds-Karp flow      O(V·E²)
        ↓
[recovery]        Reassign classes       min-change
        ↓
[json_writer]     output/timetable.json
        ↓
[frontend]        Interactive UI
```
